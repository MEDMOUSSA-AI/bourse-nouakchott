## تعدد اللغات (عربي / فرنسي)

الموقع مبني الآن بنظام الترجمة القياسي في Django (i18n):

- اللغة الافتراضية: العربية (RTL). اللغة الثانية: الفرنسية (LTR).
- زر تبديل اللغة موجود أعلى كل صفحة (داخل شريط التنقل بعد تسجيل الدخول، وأعلى صفحات الدخول/التسجيل قبله).
- تبديل اللغة يُخزَّن في جلسة المستخدم (session) عبر `django.middleware.locale.LocaleMiddleware`.
- ملفات الترجمة موجودة في `locale/fr/LC_MESSAGES/django.po` (النصوص الفرنسية) و`.mo` المُصرَّف منها.

### إن أردت تعديل أو إضافة نصوص مترجمة لاحقًا

```bash
# 1. بعد إضافة/تعديل نص عربي جديد في القوالب أو ملفات Python (استخدم {% trans %} أو gettext)
python manage.py makemessages -l fr

# 2. افتح locale/fr/LC_MESSAGES/django.po وأضف الترجمة الفرنسية أمام كل msgid جديد

# 3. صرّف الملفات لتصبح فعّالة
python manage.py compilemessages
```

يتطلب هذا وجود أداة `gettext` مثبتة على الجهاز (على أوبنتو/دبيان: `sudo apt-get install gettext`).

## التشغيل محليًا

```bash
# 1. إنشاء بيئة افتراضية (اختياري لكن يُنصح به)
python -m venv venv
venv\Scripts\activate      # على PowerShell / Git Bash في ويندوز

# 2. تثبيت الحزم
pip install -r requirements.txt

# 3. إعداد متغيرات البيئة
cp .env.example .env
# افتح .env وعدّل SECRET_KEY، واترك DATABASE_URL فارغًا لاستخدام SQLite محليًا

# 4. تجهيز قاعدة البيانات
python manage.py migrate

# 5. إنشاء حساب مدير منصة (Superuser)
python manage.py createsuperuser

# 6. تشغيل الخادم
python manage.py runserver
```

افتح المتصفح على:
- `http://127.0.0.1:8000/register/` — إنشاء حساب جديد (اختر الدور)
- `http://127.0.0.1:8000/login/` — تسجيل الدخول
- `http://127.0.0.1:8000/admin/` — لوحة إدارة Django (بحساب Superuser)

## الربط بـ PostgreSQL على Render

في إعدادات الخدمة على Render، أضف متغير بيئة:
```
DATABASE_URL=<رابط قاعدة بيانات PostgreSQL من Render>
```
المشروع يكتشف تلقائيًا وجود `DATABASE_URL` ويستخدم PostgreSQL بدلاً من SQLite (نفس الطريقة المستخدمة في Wassel).

**Build Command المقترح على Render:**
```
pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate
```

**Start Command:**
```
gunicorn config.wsgi:application
```
